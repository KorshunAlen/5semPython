## 1 Задание

Этот код реализует сопрограмму (корутину), которая генерирует числа Фибоначчи по запросу, передаваемому через yield. 

    def my_genn():
        """Сопрограмма"""
        while True:
            number_of_fib_elem = yield
            print(number_of_fib_elem)
            # Создаем список чисел Фибоначчи по указанному количеству
            a, b = 0, 1
            fib_list = [a, b]  # Начальные элементы
            for _ in range(2, number_of_fib_elem):  # Начинаем с третьего числа и так далее
                a, b = b, a + b
                fib_list.append(b)
    
            # Используем itertools.islice для получения первых N чисел из fib_list
            l = list(itertools.islice(fib_list, number_of_fib_elem))  # Ограничиваем количество чисел
    
            yield l

Алгоритм:
1. В бесконечном цикле она ожидает получения числа через yield. Это число будет определять, сколько элементов ряда Фибоначчи нужно вернуть.
2. После того как число number_of_fib_elem передано в корутину, она начинает генерировать последовательность чисел Фибоначчи. Первые два числа фиксированы: 0 и 1.
3. Числа Фибоначчи генерируются в цикле, начиная с третьего числа.
4. С помощью itertools.islice ограничиваем количество чисел в последовательности до значения, переданного через yield.
5. Возвращается список первых number_of_fib_elem чисел Фибоначчи.

# Задание 2

Код представляет собой реализацию класса FibonacchiLst, который позволяет перебирать элементы списка и возвращать только те из них, которые принадлежат числам Фибоначчи. 

1) Конструктор класса __init__ в Python — это специальный метод, который автоматически вызывается при создании нового объекта класса. Его основная роль заключается в инициализации (настройке) атрибутов объекта. Конструктор используется для того, чтобы задать начальные значения переменным, которые будут храниться внутри объекта класса, и подготовить объект к дальнейшему использованию.
        
        def __init__(self, lst):
            self.lst = lst
            self.idx = 0  # Инициализируем индекс для перебора элементов списка
            self.fib_set = set(self.generate_fib_up_to(max(lst)))  # Множество чисел Фибоначчи до максимального элемента из списка

Что делает этот код:

self.lst: сохраняет переданный список, элементы которого будут проверяться на принадлежность числам Фибоначчи.
self.idx: инициализирует индекс, который используется для обхода списка.
self.fib_set: создает множество чисел Фибоначчи до максимального элемента в списке, с помощью функции generate_fib_up_to

2) Метод generate_fib_up_to:

        def generate_fib_up_to(self, n):
            """Генерирует числа Фибоначчи до n."""
            fib = [0, 1]
            while fib[-1] <= n:
                fib.append(fib[-1] + fib[-2])
            return fib
    
Что делает этот код:

generate_fib_up_to(n): создает список чисел Фибоначчи, которые не превышают заданного значения n.
Начинает с двух первых чисел Фибоначчи: [0, 1], и затем добавляет новые числа, суммируя последние два числа последовательности до тех пор, пока следующее число не станет больше n.
Возвращает список всех чисел Фибоначчи до n включительно.

3) Метод __iter__(): возвращает сам экземпляр класса, позволяя использовать объект FibonacchiLst в цикле for, как стандартный итератор.

        def __iter__(self):
   
            return self  # Возвращаем экземпляр класса, чтобы поддерживать протокол итераторов

   Метод нужен для того, чтобы класс мог работать с конструкциями типа for item in fib_lst.

4) __next__(): этот метод используется для итерации по элементам списка lst.

        def __next__(self):
            while self.idx < len(self.lst):  # Проверяем все элементы списка
                res = self.lst[self.idx]  # Получаем текущий элемент списка
                self.idx += 1  # Увеличиваем индекс для следующего элемента
                if res in self.fib_set:  # Проверяем, является ли элемент числом Фибоначчи
                    return res  # Если да, возвращаем его
            raise StopIteration  # Если мы перебрали все элементы, выбрасываем исключение StopIteration


Проверяет все элементы списка, начиная с индекса self.idx.
-Если элемент является числом Фибоначчи (то есть он присутствует в множестве self.fib_set), возвращает его.
-Если элемент не является числом Фибоначчи, просто переходит к следующему элементу.
-Если список перебран полностью, выбрасывает исключение StopIteration, чтобы завершить итерацию.
